# Sorting Center — Система управления заказами

Веб-приложение для внутреннего учёта и управления заказами сортировочного центра. Разработано как пет-проект для отработки навыков разработки и тестирования веб-приложений.

## 📌 О проекте

Приложение позволяет сотрудникам разных сортировочных центров (СЦ) вести учёт проблемных заказов: создавать, редактировать, искать и скрывать их. Каждый пользователь работает в контексте своего СЦ (например, «Уфа», «Грибки», «Екатеринбург»).

## 🛠 Стек технологий

- **Бэкенд:** C#, ASP.NET Core MVC (.NET 8)
- **База данных:** PostgreSQL
- **ORM:** Entity Framework Core (Code First, Migrations)
- **Фронтенд:** HTML, CSS (Bootstrap 5), JavaScript (jQuery, jQuery Validation)
- **Иконки:** Font Awesome

## ⚙️ Функциональность

### Для пользователя (сотрудника СЦ)

- **Просмотр заказов** — таблица с заказами, отфильтрованными по текущему СЦ; скрытые заказы вынесены на отдельную страницу. У каждого заказа отображается статус (цветной бейдж) и тип проблемы.
- **Поиск** — по номеру заказа или номеру грузоместа: частичное совпадение, без учёта регистра.
- **Просмотр деталей** — карточка заказа со всеми полями (кнопка Details в строке таблицы).
- **Создание заказа** — форма с валидацией обязательных полей; дата создания проставляется автоматически (UTC); СЦ отгрузки и поставки выбираются из общего списка СЦ и не могут совпадать.
- **Редактирование заказа** — изменение данных существующего заказа с той же валидацией.
- **Скрытие / восстановление (soft delete)** — заказ можно скрыть из общего списка (перемещается на страницу «Скрытые заказы») и восстановить обратно.
- **Удаление** — полное удаление заказа из базы данных с подтверждением действия.
- **Переключение контекста СЦ** — выпадающий список в шапке: таблица и заголовок обновляются.

### Технические особенности

- **Валидация:** на клиенте (jQuery Validation Unobtrusive) и на сервере (Data Annotations + проверки в контроллере).
- **Работа с датами:** все даты хранятся в UTC; поле ввода даты на формах отсутствует — дата ставится сервером, на клиенте отображается в локальном времени.
- **Защита от CSRF:** `[ValidateAntiForgeryToken]` на POST-запросах.
- **Миграции БД:** применяются автоматически при старте приложения.
- **Инициализация данных:** при первом запуске база заполняется тестовыми заказами для разных СЦ.

## 🚀 Запуск проекта

### Требования

- .NET 8 SDK
- PostgreSQL (запущенный локально или в Docker)
- Visual Studio 2022 / VS Code / Rider

### Настройка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Rusya111/One_more_sorting_center.git
   cd One_more_sorting_center
   ```

2. В `appsettings.json` укажите строку подключения к своей базе:

   ```json
   "ConnectionStrings": {
     "DefaultConnection": "Host=localhost;Port=5432;Database=sorting_center;Username=postgres;Password=ваш_пароль"
   }
   ```

3. Примените миграции и запустите проект:

   ```bash
   dotnet ef database update
   dotnet run
   ```

   При первом запуске база автоматически заполнится тестовыми заказами.
