# Sorting Center — Система управления заказами

Веб-приложение для внутреннего учета и управления заказами сортировочного центра. Разработано как пет-проект для отработки навыков разработки и тестирования веб-приложений.

## 📌 О проекте

Приложение позволяет сотрудникам разных сортировочных центров (СЦ) вести учет проблемных заказов: создавать, редактировать, искать и скрывать их. Каждый пользователь работает в контексте своего СЦ (например, «Уфа», «Грибки», «Екатеринбург»).

**Стек технологий:**
- **Бэкенд:** C#, ASP.NET Core MVC (.NET 8)
- **База данных:** PostgreSQL
- **ORM:** Entity Framework Core (Code First, Migrations)
- **Фронтенд:** HTML, CSS (Bootstrap 5), JavaScript (jQuery, Validation)
- **Иконки:** Font Awesome

## ⚙️ Функциональность

### Для пользователя (сотрудника СЦ)
- **Просмотр заказов:** таблица с заказами, отфильтрованными по текущему СЦ и скрытым статусом.
- **Поиск:** по номеру заказа или номеру грузоместа (поиск работает по частичному совпадению, регистронезависимый).
- **Создание заказа:** форма с валидацией обязательных полей (номер заказа, грузоместо, СЦ отгрузки/поставки, статус, тип проблемы).
- **Редактирование заказа:** изменение данных существующего заказа.
- **Скрытие/Восстановление (Soft Delete):** заказ можно скрыть из общего списка (он перемещается на страницу «Скрытые заказы») и восстановить обратно.
- **Удаление:** полное удаление заказа из базы данных с подтверждением действия.
- **Смена контекста СЦ:** выпадающий список в шапке позволяет переключиться на другой сортировочный центр (данные таблицы и заголовок обновляются).

### Технические особенности
- **Валидация:** на клиенте (jQuery Validation Unobtrusive) и на сервере (Data Annotations в моделях).
- **Работа с датами:** все даты хранятся в UTC, на клиенте конвертируются в локальное время.
- **Защита от CSRF:** использование `[ValidateAntiForgeryToken]` на POST-запросах.
- **Миграции БД:** автоматическое применение миграций при старте приложения.
- **Инициализация данных:** при первом запуске база заполняется тестовыми заказами для разных СЦ.
